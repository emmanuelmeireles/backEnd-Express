# Back-end Express

Aplicação back-end construída com Node.js e Express, demonstrando a criação de rotas, organização de serviços e desenvolvimento de APIs.

## Objetivo

Servir como base para aplicações Full Stack que precisam expor dados e regras de negócio por meio de endpoints HTTP.

## Competências demonstradas

- Criação de APIs com Node.js e Express;
- Organização de rotas;
- Estruturação de serviços back-end;
- Integração com aplicações front-end e mobile;
- Fundamentos de desenvolvimento Full Stack;
- Preparação para validação, autenticação e persistência de dados.

## Tecnologias

`Node.js` · `Express` · `JavaScript` · `REST API`

## Como executar

```bash
npm install
npm start
```

Caso o projeto utilize outro script de execução, consulte o `package.json`.
